# 📦 Project Handoff: House of Midori

## 📝 Overview
House of Midori is a responsive matcha-themed website created as a final project. It allows users to explore matcha recipes, drinks, snacks, café recommendations, and personal matcha photography.

## 🛠 Tech Stack
* **Language:** HTML, CSS, JavaScript
* **Framework:** None
* **Database:** None
* **Design Tool:** Canva
* **Hosting:** GitHub Pages

## ⚙️ Setup & Installation
Follow these steps to run the project locally:

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure the main files are present:
   * `index.html`
   * `ABOUT.html`
   * `RECIPE.html`
   * `DRINKSnSNACKS.html`
   * `CONTACT.html`
   * `RECOS.html`
   * `css/style.css`
   * `images/`
4. Open `index.html` in a browser.
5. No installation, database, or extra setup is needed.

## ⚠️ Vital Info (Read This!)
* **Secret Keys:** No secret keys or API keys are used.
* **Tricky Parts:**
  * The website uses different responsive layouts for desktop, tablet/iPad, and mobile.
  * The search bar appears differently on desktop and mobile/tablet.
  * Recipe and café recommendation sections use anchor links, so IDs should not be renamed unless the links are also updated.
  * Images were optimized using WebP format to improve Lighthouse performance.
  * Logo and icon files were resized to improve mobile performance.
