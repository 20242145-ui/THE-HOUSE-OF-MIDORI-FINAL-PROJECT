# House of Midori

House of Midori is a responsive matcha-themed website created as a final project. The website showcases matcha recipes, drinks, snacks, café recommendations, and personal matcha photography in a modern dark aesthetic.

---

## Features

- Responsive design for desktop, tablet/iPad, and mobile
- Matcha drink and snack recipes
- Café recommendation section
- Search functionality
- Matcha photography gallery
- Optimized images and performance improvements

---
